# 📱 Система нормализации номеров телефонов

## Описание
Система автоматически нормализует все номера телефонов, что позволяет пользователям вводить номера в любом удобном формате.

## Поддерживаемые форматы ввода

### ✅ Принимаются все форматы:

1. **С плюсом и пробелами:** `+7 777 123 45 67`
2. **С плюсом без пробелов:** `+77771234567`
3. **С дефисами:** `+7-777-123-45-67`
4. **Со скобками:** `+7 (777) 123-45-67`
5. **Российский формат с 8:** `8 777 123 45 67`
6. **Без кода страны:** `7771234567`
7. **Любая комбинация:** `+7 777-123 4567`

## Как это работает

### 1. Нормализация при сохранении
При создании бронирования номер автоматически преобразуется в стандартный формат:
```
Ввод: +7 777 123 45 67
Сохраняется: +77771234567
```

### 2. Нормализация при входе
При входе в профиль номер также нормализуется перед поиском:
```
Пользователь вводит: +7 777 123 45 67
Система ищет: +77771234567
✅ Найдено!
```

### 3. Автоматическое преобразование 8 → +7
```
Ввод: 8 777 123 45 67
Преобразуется: +77771234567
```

## Рекомендации

### При вводе номера:
1. Используйте любой удобный формат
2. Система автоматически приведет к стандарту
3. При входе используйте тот же номер (в любом формате)

### Примеры корректных номеров:
- ✅ `+77771234567`
- ✅ `+7 777 123 45 67`
- ✅ `8 777 123 45 67`
- ✅ `+7-777-123-45-67`
- ✅ `+7 (777) 123-45-67`

### Примеры некорректных номеров:
- ❌ Слишком короткий: `+7 123`
- ❌ Другая страна без нормализации: `+1 234 567 8900`
- ❌ Буквы: `+7 abc def gh ij`

## Безопасность

- Пароли проверяются через bcrypt
